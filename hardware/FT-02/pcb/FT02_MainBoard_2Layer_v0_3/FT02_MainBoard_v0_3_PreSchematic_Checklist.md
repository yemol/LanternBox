# FT-02 v0.3 正式原理图前检查表

## 必须由实物确认

- [ ] ESP32-S3 模组完整型号：WROOM-1 N16R8 或 WROOM-1U N16R8
- [ ] USB-C 插座具体型号、安装方式和外壳开孔高度
- [ ] MicroSD 卡座具体型号和插卡方向
- [ ] 电子纸接口实物针脚顺序
- [ ] GNSS 接口实物针脚顺序和供电电压
- [ ] LoRa 子板接口实物针脚顺序和供电电压
- [ ] CardKB2 插头方向
- [ ] 主板最大尺寸和四个安装孔坐标

## 电气检查

- [ ] TPS62132 官方参考电路参数完整复核
- [ ] USB-C CC1/CC2 各自 5.1k 下拉
- [ ] USB D+/D- ESD 器件低电容
- [ ] EN 上拉、复位电容和按键
- [ ] GPIO0 上拉和 BOOT 按键
- [ ] SD CS 上拉
- [ ] I²C 上拉不与外部模块重复过重
- [ ] 所有外接口 UART/I²C 电平为 3.3V
- [ ] VCC_GNSS/VCC_LORA 焊盘不能同时桥接 3.3V 与 5V
- [ ] 每个外接口旁有 GND 回流针脚或就近地过孔

## PCB 检查

- [ ] ESP 天线伸出板边或严格净空
- [ ] 天线所有层无铜、无走线、无器件
- [ ] Buck SW 节点面积最小
- [ ] SD SCK 短且不跨地缝
- [ ] USB 差分对等长、连续参考地
- [ ] 底层尽量完整 GND
- [ ] 电源和外接口附近有地过孔围栏
- [ ] DRC 0 error
- [ ] 首板上电采用限流电源
