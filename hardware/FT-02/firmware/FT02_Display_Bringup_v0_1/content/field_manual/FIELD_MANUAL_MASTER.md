# FT-02 现场行动手册主规范 v0.1

## 一、固定方针

FT-02 知识库定位为**现场动作指导终端**。它不承担百科、科普和理论讲解，只处理一个问题：

> 遇到某种现场情况后，使用者下一步具体做什么。

硬规则：

1. 每张卡只解决一个现场问题。
2. 每一步以动作动词开头。
3. 能量化时必须写数字、距离、时间、温度或完成条件。
4. 不单独使用“适量、适当、必要时、尽快、视情况”等模糊词。
5. 必须给出替代材料或缺少标准工具时的处理方法。
6. 必须写明停止、撤离、转运或升级求助条件。
7. 必须写明禁止动作。
8. 必须有完成检查，使用者能判断是否已经做到位。
9. 医疗、饮水、食品和动物暴露内容必须保留官方来源与复核记录。
10. 不收录无人值守的伤害性陷阱、尖刺机关、套索和攻击性武器制造。动物防护只采用距离、屏障、声音预警、气味管理、撤离和最后防护工具。

## 二、正式分类

1. **急救医疗**：现场伤病识别、立即处置与转运前维持
2. **水与净化**：水源判断、过滤、消毒与安全储存
3. **食物与保存**：断电、污染与交叉污染情况下的处理
4. **火源与保温**：火灾、燃烧设备、一氧化碳与体温防护
5. **卫生防疫**：手卫生、排泄物、污水与清洁分区
6. **工具与维修**：现场故障隔离、临时修复与安全恢复
7. **能源与用电**：电池、太阳能、保险丝和低压系统处置
8. **导航与通讯**：迷失、坐标、求救信息与联络格式
9. **避难与转移**：庇护点选择、留守撤离和夜间移动
10. **野生动物与营地防护**：减少吸引、保持距离、驱离、预警与撤离
11. **安全与组织**：人员清点、结伴、交接和值守记录

“快速应急”不是独立分类，而是从全部分类中抽取 `quick_access: true` 的卡片组成快捷入口。

分类 Card 的 `summary` 只写一行用途提示：

- 最多 24 个显示单元，约等于 12 个全角中文字符；
- 不写完整能力范围，不罗列多个场景；
- 详细范围由分类内行动卡承担。

## 四、保存结构

```text
FT02_Field_Manual_Content_v0_1/
├── FIELD_MANUAL_MASTER.md          # 唯一总说明：方针、分类、阶段、历史锚点
├── source/
│   ├── manifest.yaml               # 知识包版本、来源注册表、构建目标
│   ├── categories.yaml             # 分类定义与排序
│   └── phase1_cards.yaml            # 第一阶段全部动作卡，唯一内容源
├── schema/
│   └── card_schema_v1.json          # 卡片字段规范
└── tools/
    ├── validate_cards.py            # ID、分类和必填动作段校验
    ├── build_ft02_field_manual.py   # 生成 FT-02 SD 运行数据包
    └── validate_runtime_pack.py     # 校验 CRC、偏移和卡片记录
```

当前阶段不为每张卡建立单独 Markdown，避免文件数量失控。内容以结构化 YAML 保存，便于：

- 直接审阅和版本控制；
- 按分类筛选；
- 自动生成拼音、关键词和编号索引；
- 自动分页成 FT-02 Card；
- 同一内容同步生成 Core、FT-01、FT-02 和 Study Terminal 版本；
- 后续转换为二进制知识包。

## 五、终端编译后的目标结构

源内容经 Core 构建器编译后，FT-02 的 SD 卡只保存运行文件：

```text
/knowledge/field_manual/
├── manifest.bin        # FT-02 启动时读取的固定格式清单
├── manifest.json       # 人员可读的版本与数量信息
├── categories.bin      # 分类、顺序、摘要与卡片范围
├── cards.idx           # 卡片编号、标题、摘要与正文偏移
├── cards.dat           # 卡片动作正文连续存储
├── quick.idx           # “快速应急”入口卡片索引
├── search.idx          # 编号、标题与关键词索引，后续搜索使用
├── sources.json        # 来源注册表，不在普通阅读页显示
└── checksums.sha256    # 完整性校验
```

FT-02 不直接解析 YAML，也不在设备上修改正文。收藏、最近阅读、书签等用户状态单独保存，不能写回知识包。
