# Third-party notices

## Noto Sans CJK generated bitmap data

FT-02 includes generated bitmap glyph data produced from Noto Sans CJK Regular and Bold during build preparation, including the global CJK, map and footer font packs.

The source font files are licensed under the SIL Open Font License 1.1. No font file is included or redistributed in this package. The package contains only generated bitmap glyph data required by the FT-02 firmware.

Relevant generators include:

```text
tools/generate_ft02_global_cjk_font.py
tools/generate_ft02_global_cjk_bold_font.py
tools/generate_ft02_global_cjk20_optimized_font.py
tools/generate_ft02_map_fonts.py
```

## SparkFun WM8960 Arduino Library

`src/FT02_AudioLog.cpp` uses the SparkFun WM8960 Arduino Library for WM8960 I2C register configuration. PlatformIO resolves version `1.0.3` from the declared dependency. The library is distributed under its upstream MIT license.

## Espressif I2S standard driver

The full-duplex I2S path uses the standard I2S driver supplied by the configured Arduino-ESP32 / ESP-IDF platform. No Espressif source file is vendored into this package.

## xpinyin database / Unihan-derived Mandarin readings

The generated `src/FT02_PinyinImeData.h` uses Mandarin spelling data derived during build preparation from the `xpinyin` database distributed with TeX Live. The xpinyin database states that it is generated from the Unicode Unihan database and is distributed under the LaTeX Project Public License (LPPL), version 1.3c or later. Candidate ordering is FT-02-specific and generated separately.
