- PSRAM

## 重点验收
1. 三页均不得越过底部按键栏。
2. 左/右翻页应为 1/3 -> 2/3 -> 3/3。
3. 系统时间年份仅接受 2025..2099，转换失败或年份越界必须 FAIL。
4. Host UART 显示协议版本、接收行数和 UART 错误。
5. 通讯错误显示 RX错误 / UART错误 / Radio复位。
6. 启动状态若为 Panic / Watchdog / Brownout，应 WARN。
7. 自检不得重新初始化 GNSS、罗盘、LoRa 或音频。
