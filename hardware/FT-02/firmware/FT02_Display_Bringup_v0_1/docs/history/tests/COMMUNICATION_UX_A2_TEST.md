# FT-02 v2.75f Communication UX A2

## 1. 发件箱清空快捷键
- 不再使用 C。
- C 在 CardKB2/InputManager 中对应 RIGHT，所以与上下/翻页浏览冲突。
- 改为 K 清空。

流程：
1. 发件箱按 K。
2. 显示“确认清空全部发件记录？”
3. 确认键执行清空。
4. B / ESC 取消。

## 2. 撤销消息增加明确确认页
对“排队中/等待确认”的消息按 DEL：
1. 进入“撤销投递”确认页。
2. 确认键执行撤销。
3. B / ESC 取消。
4. 成功后回到发件箱并显示“已撤销当前待投递消息”。

对“已送达”的消息按 DEL：
- 不进入撤销流程。
- 直接提示“消息已经投递，无法撤销”。

## 3. 通讯模块文案
用户可见状态继续使用“通讯模块：在线/离线”，不显示“LR01：在线/离线”。
