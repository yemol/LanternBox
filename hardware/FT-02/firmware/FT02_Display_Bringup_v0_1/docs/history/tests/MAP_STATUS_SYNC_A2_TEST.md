# FT-02 v2.75i Map Status Sync A2

## 1. GPS 状态栏
- 在定位记录页等待首次 Fix。
- 下方定位信息从“未定位”变为 2D/3D 后，顶部 GPS 状态应立即同步为 2D定位/3D定位。
- 不应继续等待定位记录页的 30 秒刷新周期。

## 2. 地图双标记
- GNSS 跟随开启且 Fix 有效：只显示真实位置箭头，不显示地图中心十字光标。
- 手动平移/缩放后退出 GNSS 跟随：中心十字光标重新显示，作为地图中心参考。

## 3. 罗盘校准
QMC5883L 属于磁力计/电子罗盘，不是陀螺仪。当前 LR01 HOST_PROTOCOL_A2 没有校准命令，因此本版不在 Core 做假校准。后续应在 LR01 增加 COMPASS_CAL_START / STATUS / SAVE / CANCEL 后，由 Core 提供“罗盘校准”设置页。
