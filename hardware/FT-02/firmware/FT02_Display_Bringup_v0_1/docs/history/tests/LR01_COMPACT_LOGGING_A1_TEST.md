# LR01 Compact Logging A1 Test

默认 FT02_LR01_LOG_LEVEL=1。

应保留：
- LR01 READY / OFFLINE / LINK TIMEOUT
- MESH_RX
- MESH_TX_ACCEPTED / SENT / FAILED / RESULT
- MESH_DELIVERY ACK / TIMEOUT
- MESH_NODE_END / 节点列表完成
- LR01_ERR

正常情况下不应每秒刷：
- CORE_PING / LR01_PONG
- 周期 NAV_STATE
- 周期 RADIO_STATE
- 周期 SYSTEM_STATE

如需完整协议调试，把 FT02_LR01_LOG_LEVEL 改为 2。
