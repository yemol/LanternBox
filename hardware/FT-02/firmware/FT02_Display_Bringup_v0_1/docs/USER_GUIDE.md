# FT-02 用户操作说明

## 1. 基本按键

- `D / Z / X / C`：上 / 左 / 下 / 右
- `ENTER / SPACE`：确认
- `B / ESC`：返回
- `H`：帮助
- `DEL`：在支持的页面执行删除或取消
- `K`：在“设备状态”页进入罗盘校准

CardKB2 使用拼音输入时：
- `Sym + V`：候选上一页
- `Sym + B`：候选下一页

## 2. 首页

首页主要模块：

- 知识库
- 地图导航
- 日志记录
- 定位记录
- 内部通讯
- 设备状态

## 3. 地图导航

地图使用 SD 卡中的离线 PBF 地图。

实时定位有效时：

- 首次获得 Fix 后自动定位到当前位置。
- 地图显示真实 GNSS 位置。
- 罗盘有效时显示方向箭头。
- 正常移动时使用局部刷新，减少电子纸等待。
- 当前位置离开中央安全区域后自动重新居中。

方向箭头使用 LR01 提供的 `heading`，Core 不自行读取罗盘。

手动浏览地图后，中心十字重新出现，用来表示当前浏览中心。

## 4. 定位记录

定位记录页显示：

- Fix 类型
- 经纬度
- 已用/可见卫星
- HDOP
- 速度
- 时间

顶部状态栏会跟随 LR01 的实时 GNSS 状态更新。

## 5. 内部通讯

通讯模块由 LR01 运行 Meshtastic。

支持：

- 广播消息
- 私信
- 节点列表
- 可靠消息投递状态
- ACK / TIMEOUT

`SENT` 仅代表 LR01 已完成本地发送；只有 `DELIVERY ACK` 才视为可靠送达。

## 6. 设备状态 / 系统自检

设备状态页为三页系统自检，可检查：

- ESP32 / PSRAM / SD / CardKB2 / Audio
- LR01 Host UART
- GNSS / GNSS Fix / 罗盘
- LoRa / 节点网络
- 地图 / 应急手册 / 拼音
- 存储空间 / 内存 / 通讯错误 / 启动状态

左右方向键翻页，`ENTER` 重新运行自检。

按 `K` 进入罗盘校准。

## 7. 罗盘校准

入口：

```text
首页
→ 设备状态
→ K 罗盘校准
```

进入页面后 Core 会向 LR01 查询当前校准状态。

### 开始

按 `ENTER`：

```text
COMPASS_CAL_START
```

随后缓慢转动设备，并在空间中做完整的“8”字运动。

页面显示：

- 校准状态
- 进度
- 质量
- 样本数
- X / Y / Z 覆盖范围
- 当前是否已经存在持久化校准

### 保存

当状态变成 `READY` 后按 `ENTER` 保存。

只有 LR01 判定质量达到可保存标准时，新参数才会写入 NVS 并接管 heading。

### 取消

校准进行中按 `DEL` 取消本次校准。

如果之前已经存在有效校准，取消不会删除旧参数。

### 重置

按 `R` 删除 LR01 中已经持久化的罗盘校准。

系统会先进入二次确认页，避免误操作。

## 8. 状态含义

罗盘质量：

- `0`：传感器或 heading 无效
- `1`：传感器正常，但没有已保存校准
- `2`：已保存可用校准
- `3`：已保存高质量校准

GNSS：
- `2D定位`：已有二维 Fix
- `3D定位`：已有三维 Fix
- `搜索中`：当前没有有效 Fix
