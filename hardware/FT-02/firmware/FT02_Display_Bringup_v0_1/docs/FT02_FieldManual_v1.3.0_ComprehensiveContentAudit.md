# FT-02 FieldManual v1.3.0 全面内容验收审计

审计对象：**v1.3.0-a3.3 / 199 张行动卡 / 9 分类 / 32 Quick / 141 图解页**。

本次审计不修改知识包，只给出正式验收结论和下一版修订清单。标准包括：重复性、事实真实性、来源可靠性、新手可执行性、现场适用性、风险表达和图解必要性。

## 一、总体验收结论

- **P0 必须修正：4 张**。这些问题会改变高风险现场动作，不建议原样冻结为最终内容基线。
- **P1 建议修改：20 张**。内容方向基本正确，但存在术语、离线可执行性、来源匹配或新手操作表达问题。
- **建议迁移到设备维护：2 张**。内容有用，但不属于通用 FieldManual。
- **其余直接保留：173 张**。未发现足以改变现场动作的明显事实错误或新的重复问题。
- **重复性：通过。** 当前高相似度项主要是成人/婴儿CPR、成人/婴儿气道梗阻、脱水/腹泻补液等有意分开的不同处置分支，不建议再合并。
- **结构完整性：通过。** 199/199 均包含“适用情况、判断、操作步骤、不要做、升级处理、完成检查”。
- **引用完整性：通过。** 所有卡片 source key 均能在 sources.json 中解析；卡内引用未发现失效 Card ID。

## 二、P0：正式冻结前必须修正

### MED038《严重胸部创伤》

严重胸部创伤中的开放胸伤处置不够完整。应明确：开放胸伤可保持开放，或用清洁非封闭性敷料/专用带阀胸封；若呼吸恶化应松开/移除覆盖，并持续监测。不能只写“控制外出血”。

### MED043《婴儿完全气道梗阻》

婴儿严重气道梗阻的胸冲击手法需要与2025 AHA更新统一。当前“两指胸冲击”与AHA 2025更新不一致，应采用当前权威版本并同步图解。

### MED044《婴儿CPR与AED》

婴儿CPR仍写“单人可按训练使用两指法”。AHA 2025已明确两指胸外按压不再推荐，应改为双拇指环抱胸廓或单手掌根法，并同步图解。

### CMP013《落地或损坏电线》

落地电线安全距离写成约3米/10英尺，容易把“架空线作业净距”误用于落地电线。面向公众的保守规则应至少约11米/35英尺，潮湿环境更远；若已在危险区内应双脚并拢小碎步移开。

## 三、P1：真实性基本成立，但需要提高新手可执行性/来源质量

- **MED006《疑似骨折与关节损伤》**：“末端血运”对新手不友好，正文应直接写成“检查伤处以下手/脚的颜色、温度、感觉，有无麻木刺痛”，避免术语。
- **MED014《晕厥后的处理》**：“恢复体位”是关键动作但卡内没有步骤、也没有图。应给3步动作或直接配图，否则新手很可能知道名字却不会摆。
- **MED023《眼部化学物或异物》**：首次出现SDS应写成“安全数据表（SDS）”，并强调冲洗优先，不能因为寻找SDS延误眼部冲洗。
- **MED026《中毒暴露初步处理》**：首次出现SDS应展开为“安全数据表（SDS）”；“联系中毒咨询机构”应兼容无联网环境，提示使用当地预存号码/标签急救信息。
- **MED033《哮喘发作》**：“储雾罐”应解释为“吸入器间隔器/储雾罐（spacer）”；步骤可更明确地区分有/无间隔器。
- **MED035《疑似低血糖》**：“胰高血糖素”应写成“本人处方的胰高血糖素急救装置”，避免新手误以为可自行配药或决定剂量。
- **MED039《严重腹部创伤》**：“无粘连材料”对新手偏专业。应写成“用清洁、温暖的生理盐水或清洁水湿润敷料，松松覆盖外露组织，不压回腹腔”。
- **MED045《蜱虫附着处理》**：操作本身基本正确，但来源应升级到当前CDC蜱虫移除指南；“保存蜱虫”不应作为默认目标，优先拍照/记录日期地点并按当地建议处理。
- **SUR019《过滤后消毒饮水》**：“滤芯标称能力”应改成“看包装/说明书写明能过滤哪些病原体”，让新手知道具体要看什么。
- **REP024《便携炉具点不着：先停气，再查冷却后的连接》**：“回火”属于炉具术语。应改成“火焰向炉头内部倒烧/出现异常轰鸣或喷火”等能直接观察的现象。
- **CMP024《灾后门与入口临时加固》**：门楔/横撑的原则安全，但文字不足以让新手判断“牢固结构”和横撑受力位置。建议加一张正确/错误示意图，并明确“只作临时关闭，不是结构加固认证”。
- **CMP028《低张力外围报警线》**：低张力报警线的安全原则很好，但必须靠图说明“低张力、易脱开、不能跨通道”。这是典型“文字看懂但搭错就危险”的条目。
- **CMP045《熊接近营地：不要跑，不要丢食物》**：熊接近营地卡对一般接近很保守，但真正冲锋/攻击时只写“按当地熊种指南”，离线终端在关键时刻仍缺最后一层。建议增加黑熊与棕熊/灰熊攻击分支或独立卡，并明确防御性与捕食性行为差异。
- **CMP050《鼠类进入物资区：先断食源再封缝》**：鼠类污染清洁应补充：封闭小屋/仓房在大量鼠迹情况下先开门窗通风约30分钟，戴手套并湿润消毒后清理，禁止干扫/吸尘扬尘。
- **DIS020《长时间被重物压住：不要贸然快速移开》**：“不要贸然快速移开”方向正确，但要区分“长时间、大面积、稳定压迫”与火/水/气道等立即生命危险，避免新手把任何可轻易移开的压物都理解为不能动。
- **FOD003《罐头与包装食品检查》**：鼓包/渗漏罐头应强调“不要为了闻味而打开或凑近闻”。肉毒毒素不能靠看、闻、尝排除；可疑容器直接隔离丢弃。
- **FOD014《小型动物箱式活捕陷阱》**：理念安全，但“滑门/翻门/触发片/诱饵托”仅靠文字不足以让新手可靠搭建；当前来源也不足以直接验证这套具体自制结构。建议成品活捕笼优先，自制部分必须配经过实物验证的一步一图。
- **FOD015《简易漏斗鱼笼：只用于安全浅水静水》**：漏斗鱼笼原理可靠、风险较低，但没有结构图，新手很难仅凭“朝内收窄漏斗”做出有效装置。建议加成品图、入口剖面和固定方式图。
- **COM001《紧急位置与求救报告》**：“回读”第一次出现应直接解释成“让对方把位置、人数和计划重复一遍确认”，避免通信术语。
- **COM004《多人通信必须回读确认》**：标题和正文都依赖“回读”概念，建议标题改成“关键指令必须让对方重复确认”，再把“回读”作为括号术语。

## 四、来源可靠性审计

- A：有权威外部来源：**166 张**
- C：仅内部基线：**28 张**
- B：非官方/混合来源：**4 张**
- B：官方但偏旧/单一：**1 张**

结论：医疗、灾害、饮水、食品、野生动物等高风险分类整体来源结构较好，主要依赖 American Red Cross、AHA、WHO、IFRC、CDC、FEMA/Ready.gov、NPS、OSHA/USFA 等。需要重点改进的是两类：

1. **仅 FT02_SAFE 的低风险工程/组织流程卡**。这些内容多数可以保留，但 sources.json 应逐步补厂家资料、行业指南、ICS/FEMA 通信原则或其他可追溯依据，避免“我们自己觉得安全”成为唯一证据。
2. **旧版/消费版医学页面的链接**。医疗卡应优先锁定 2025 AHA / Red Cross Guidelines Database 等当前指南，而不是长期依赖 production.redcross.org 等旧入口。内容和来源版本要同步冻结。

## 五、新手可执行性审计

199 张卡的结构已经适合现场阅读，但“有步骤”不等于“第一次看就能做”。本轮发现最主要的障碍是：**术语没有翻译成人话、动作型技能缺图、以及个别卡把关键最后一步交给“当地指南”**。

建议统一术语替换：

- `末端血运` → `手/脚颜色、温度和感觉`
- `恢复体位` → `侧卧保持气道通畅的姿势`
- `SDS` → `安全数据表（SDS）`
- `储雾罐` → `吸入器间隔器/储雾罐（spacer）`
- `胰高血糖素` → `本人处方的胰高血糖素急救装置`
- `回读` → `让接收者重复关键信息确认`
- `标称能力` → `说明书明确写出的过滤能力`
- `回火` → `火焰向炉头内部倒烧/异常喷火或轰鸣`

### A级图解优先队列

- **MED014《晕厥后的处理》**：恢复体位
- **MED038《严重胸部创伤》**：开放胸伤覆盖方式
- **MED043《婴儿完全气道梗阻》**：婴儿背击+胸冲击
- **MED044《婴儿CPR与AED》**：婴儿CPR手位
- **MED046《溺水后的复苏》**：溺水复苏：先2次呼吸再30:2
- **CMP013《落地或损坏电线》**：落地电线35英尺隔离与小碎步撤离
- **CMP024《灾后门与入口临时加固》**：门楔/可拆横撑正确受力
- **CMP025《窗户临时加固与防碎》**：窗板覆盖与固定点
- **CMP027《门窗开启声响报警》**：门窗声响报警
- **CMP028《低张力外围报警线》**：低张力易脱开报警线
- **FOD014《小型动物箱式活捕陷阱》**：箱式活捕笼结构与触发
- **FOD015《简易漏斗鱼笼：只用于安全浅水静水》**：漏斗鱼笼入口剖面
- **REP021《帐篷杆折断：先卸力再做夹板》**：帐篷杆夹板维修
- **REP022《帐篷/防水布破口：先止裂，再补片》**：防水布止裂+补片
- **REP023《水袋/水桶漏水：先隔离净水，再修补》**：水袋/水桶漏点隔离与修补
- **REP024《便携炉具点不着：先停气，再查冷却后的连接》**：炉具停气、冷却、检查顺序

图解原则不变：一个页面只表达一个动作，640×110 左右，固定端/活动端/受力方向清楚，图下必须有一句直接操作说明。没有真正降低误操作概率的图不要做。

## 六、哪些内容不应该继续放在 FieldManual 主库

- **REP018《LoRa/GNSS天线连接检查》**：LoRa/GNSS天线连接检查是FT-02设备维护知识，实用但不属于通用应急FieldManual。建议迁入未来“设备帮助/维护”，终端内继续保留。
- **REP019《SD卡读取异常排查》**：SD卡读取异常排查是FT-02本机维护知识，应迁入“设备帮助/维护”，避免污染应急知识搜索结果。

这不是删除，而是“终端内迁移”。FT-02 以后应有独立 Device Help / 设备维护知识包，FieldManual 搜索默认不混入本机故障排查。

## 七、按分类验收

- **MED（48 张）**：总体可靠，但4张医学高风险卡中有3张P0（胸伤、婴儿气道梗阻、婴儿CPR），修完后才能称医疗内容冻结。
- **SUR（25 张）**：整体成熟。没有发现高风险事实错误；主要是把“标称能力”等术语改成人话。
- **REP（21 张）**：现场维修很实用，但内部来源占比最高。建议建立“低压/无高压/不拆危险电池”的统一工程安全声明，并逐步补厂家或标准来源。REP018/019迁移设备维护。
- **CMP（44 张）**：现场价值高。CMP013落地电线距离必须修；动物/门窗/预警内容方向正确，但部分动作需要图解。
- **TOL（10 张）**：图解覆盖好、适合新手。普通野外绳结继续明确“不用于攀登/生命支持”。来源可再补强。
- **FOD（18 张）**：食品安全部分整体可靠。FOD014/FOD015最大的弱点不是原理，而是“没有图就不够可操作”；FOD003需补肉毒毒素相关表述。
- **DIS（20 张）**：整体可靠、现场性强。DIS020挤压伤需要把“不要贸然解除”写得更有条件，避免绝对化。
- **SAN（8 张）**：整体清楚且保守，可保留。后续只需继续把灰水等术语在首次出现处定义。
- **COM（5 张）**：功能上很实用，但偏内部SOP；“回读/中继”等术语需新手化，并补FEMA/ICS类来源。

## 八、是否适合继续放在终端

总体结论是 **适合**。v1.3.0 已经明显脱离“百科式堆知识”的风险，大多数卡都能在一分钟内给出下一步动作。现在不建议继续扩数量，先完成本报告的 P0/P1 修订更重要。

下一版建议不是新增大批卡，而是发布 **v1.3.1 Quality Audit Fix**：只修 P0/P1、迁移设备维护卡、补第一批关键图解，再重新跑一次二进制/媒体/搜索/Quick 审计。修完后再决定是否还有真正需要新增的场景。

## 九、审计方法与边界

- 全量 199 张：结构、来源 key、分类、文本重复、动作段落、危险措辞、术语和图解覆盖检查。
- 高风险内容：医疗、灾害、电气、食品、野生动物等按当前权威来源做针对性复核。
- 本次没有把“来源存在”自动等同于“卡片正确”；重点核对来源是否真正支持卡内动作。
- 本次没有修改 cards_source.json 或二进制知识包，因此现有 v1.3.0 仍是待修正版本，不应把本报告的结论误认为内容已经自动修复。
