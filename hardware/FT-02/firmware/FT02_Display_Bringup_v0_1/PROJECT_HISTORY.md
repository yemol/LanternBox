# FT-02 项目历史

## v2.58 · 优化 20 px 字体正式版

- 根据 v2.57 实机对比结果，正式采用 B 方案的优化 20 px 常规中文。
- 全局 20 px 字库改为灰度栅格后以阈值 170 转换为 1-bit 位图。
- 字库覆盖 22,367 个字符，替换知识库说明、分类摘要和定位记录辅助文字等小字号区域。
- 删除临时字体对比页面、`F` 键入口和 22 px 测试字库。
- 定位记录底栏恢复为 `R 重连 / B 返回`。
- 保留后台 Session、30 秒自动轨迹、中间区域局刷和 GNSS 正式接线基线。

## v2.57 · 小字号字体实机对比 A1

- 在定位记录页增加 `F` 键字体测试入口。
- 新增同屏 A/B/C 对比：当前 20 px、优化 20 px、优化 22 px。
- 优化字形通过灰度边缘覆盖后阈值化为 1-bit，减少断笔、锯齿和粗糙边缘。
- 测试包只嵌入对比页所需字符，避免在选型前增加完整字库体积。
- 字体测试页按 `B` 返回定位记录，后台 Session 与自动轨迹继续运行。
- 字体测试页禁止时钟和 GNSS 顶栏局刷，确保对比画面保持静态一致。
- 定位记录、知识库、地图、GNSS 和现场行动手册数据保持不变。

## v2.56 · 定位记录后台持续运行

- 定位记录页按 `B` 改为仅返回首页，不再自动调用 `FT02_LocationRecorderStopSession()`。
- `FT02_LocationRecorderPoll()` 继续在全局主循环执行，Session、时长、自动轨迹与 SD 写入不会因页面切换中断。
- 再次进入定位记录页时恢复原 Session ID、起点状态、点数、自动记录状态和累计时长。
- 只有用户在定位记录页明确按 `ENTER` 停止，才写入 `session_stop`。
- 保留 v2.55 中间区域局部刷新、120 次局刷后整页清理和无 Fix 保护。

## v2.55 · 定位记录 A2 与中间区域局刷

- 删除 BASE 基准点、`M` 键、`base_mark` 事件和 `base_position.json`。
- 新增 `session_origin`，每次 Session 在首次获得有效 Fix 时自动记录一次起点。
- Session 开始时已有 Fix 则立即记录起点；无 Fix 时等待首次有效定位。
- 定位记录页首次进入仍完整刷新。
- 页面运行期间改为只局部刷新 X=24、Y=78、W=752、H=350 的中间动态区域。
- 顶部状态栏和底部操作栏不再随定位记录内容更新而整页重绘。
- 中间区域累计 120 次局刷后执行一次整页清理刷新，降低长期残影风险。
- GNSS RX39 / TX38 / 38400、现场手册和地图基线保持不变。

## v2.54 · 定位记录 A1

- 首页入口由“定位搜索”改为“定位记录”。
- 保留 GNSS RX39 / TX38 / 38400 实测通讯基线和顶部真实状态。
- 新增显式 Session 开始与停止。
- 新增手动路径点、30 秒自动轨迹和 BASE 标记。
- 自动记录开启且已有 Fix 时立即写入 `auto_start`，后续写入 `auto`。
- 无 Fix 时禁止写入有效路径点；手动记点写入 `path_point_failed`，BASE 写入 `base_mark_failed`。
- 轨迹统一保存到 `/lanternbox/tracks/path_points.jsonl`。
- 最新 BASE 同步保存到 `/lanternbox/tracks/base_position.json`。
- 所有事件逐条立即落盘并执行同步，降低突然断电造成的记录损失。
- 定位记录页面保留卫星、HDOP、经纬度、海拔、速度与航向显示。
- 不修改知识库、地图、SD、CardKB2 和电子纸稳定刷新基线。

## v2.53 · GNSS 状态栏正式接入 A1

- 根据实机测试修正 GNSS UART：ESP32 RX=GPIO39、TX=GPIO38。
- 固定使用实测通过的 38400 波特率，正式运行不再轮询其他波特率。
- 顶部 GPS 状态区接入真实 GNSS 状态：连接中、无数据、数据异常、搜索中、2D定位、3D定位、通讯超时。
- 状态栏只在状态转换时更新，避免按 NMEA 频率反复刷新电子纸。
- 知识库页面继续禁止顶栏局刷，GNSS 状态只更新缓存，下一次完整页面提交时显示。
- “定位搜索”页面保留完整通讯和定位信息，并将接线显示改为 RX39 / TX38。
- R 键从“重新扫描波特率”改为“重新连接固定 38400 串口”。
- 板级配置加入 `ARDUINO_USB_CDC_ON_BOOT=1`，USB 串口可直接输出应用日志。
- 地图暂时仍使用现有固定中心点，尚未自动跟随 GNSS。

## v2.52 · GNSS 串口与定位诊断 A1

- 基于 v2.51 稳定基线增加 GNSS 独立诊断页面。
- GNSS 使用 UART1：RX=GPIO38、TX=GPIO39，P/PPS 暂不接。
- 自动扫描 9600、38400、115200、4800、57600、19200 波特率。
- 内置 GGA、RMC、GSA 最小 NMEA 解析器，不增加第三方依赖。
- 显示串口字节、有效语句、校验错误、定位类型、卫星数、HDOP、坐标、海拔和 UTC。
- 首页“定位搜索”Card 进入诊断页；Enter 刷新、R 重扫、B 返回。
- 电子纸仅在关键状态变化且间隔至少 5 秒时自动刷新，避免连续全刷。
- 地图暂不自动跟随 GNSS，待本轮硬件与定位验证通过后接入。
