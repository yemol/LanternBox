# FT-02 FieldManual v1.0.1 双重审核报告

审核日期：2026-08-20

结论：100/100 条卡片完成两轮审核并通过结构/二进制一致性校验。此结果表示未发现与所列权威资料相冲突的已知高风险指令；现场医疗仍不能替代正规训练、当地急救系统或专业诊疗。

## 第一轮：真实性 / 来源 / 风险边界

- 逐卡检查适用条件、判断、步骤、禁止事项、升级条件和完成检查。
- 医疗卡核对 American Red Cross 当前公开急救资料，并用 IFRC 2025 / AHA 2025 / WHO 对关键高风险项目二次来源交叉。
- 饮水、卫生、停电食物核对 CDC 当前资料；雷暴、山洪、涉渡、营火核对 NPS。
- 锂电池危险处置补核 EPA 2026 与 FAA 当前锂电池安全资料。
- 删除/改写过度概括、固定阈值滥用、地区依赖方法以及可能诱发二次伤害的表达。

## 第二轮：实用性 / 失败模式 / 初学者可执行性

- 逐卡检查“现场看到卡后下一分钟能否行动”。
- 检查步骤是否需要未说明的专业技能或隐含前提。
- 检查失败模式：错误复位、错误止血带、错误蛇伤处理、热射病降温不充分、损坏锂电池搬运、绊线伤害、食物靠嗅味判断等。
- 工具卡继续限定为低风险用途；不把普通绳结/临时结构包装为生命安全装备。
- 每张卡仍保留明确“不要做”和“升级处理”。

## 本次实际修改

- **MED002 威胁生命的外出血**：明确致命出血时不因缺少手套延误；增加止血带施用时间记录与禁止自行松开。
- **MED003 严重开放性伤口**：修正“已清洁覆盖”与正文不一致，严重开放伤口现场目标改为止血与覆盖保护。
- **MED008 热烧伤处理**：按当前Red Cross将冷却改为5–20分钟并强化大面积/深层/特殊部位、电化学和吸入伤升级条件。
- **MED011 热衰竭处理**：补入当前Red Cross列出的无法站立/行走、晕厥、呕吐等紧急信号。
- **MED012 热射病紧急处理**：把“更积极的全身降温”改为可执行步骤，明确冷水浸泡为优先方法，无法浸泡时持续湿润+扇风。
- **MED014 晕厥后的处理**：去除对“约一分钟”作为判断门槛的过度依赖，改为强调持续无反应/恢复异常需升级。
- **MED016 成人/儿童完全气道梗阻**：用AHA 2025第二次核对5背拍+5腹部冲击、失去反应后CPR及禁止盲扫口腔。
- **MED017 成人徒手CPR与AED**：按AHA 2025将成人按压深度明确为约5–6厘米，补充最小化中断。
- **MED020 疑似毒蛇咬伤**：按WHO全球蛇伤原则重写：完全减少活动、夹板固定、尽量搬运；移除可能存在地区差异的常规清洗；限定压力固定带适用范围。
- **MED023 眼部化学物或异物**：化学品入眼改为持续冲洗至专业接手或按SDS/中毒中心指示，避免过早停止。
- **MED025 抽搐发作保护**：把侧卧时机明确为抽搐停止后，避免普通用户在强烈抽搐过程中强行翻转。
- **MED026 中毒暴露初步处理**：增加SDS/标签优先和“未知化学品不互相中和”，避免所有化学暴露一律用同一方法。
- **MED027 腹泻/呕吐时补液**：去除固定“两天”作为主要升级门槛，改为症状与高风险人群驱动。
- **SUR010 河流涉渡决策**：去除固定“过膝”作为通用安全阈值，保留NPS支持的深/急水避让与过河前解开背包腰带。
- **SUR015 搜救信号设置**：把“三次一组”从绝对规则改为常见求救节律，并明确当地/队伍标准优先。
- **SUR018 煮沸饮水**：把CDC 6500英尺阈值明确换算为约2000米，避免模糊。
- **SUR020 野外排泄与水源卫生**：按CDC当前露营卫生指引把约60米距离同时覆盖水源、食物区和营地，并补充免洗手液的局限。
- **SUR021 是否生火的判断**：明确禁火规定也可能限制炉具，避免把燃气炉具误写成任何火险下都可用。
- **SUR023 终端与通讯电量管理**：避免把“定时LoRa收发”写成所有网络都适用，区分协议允许的主动通信与必须持续在线的接收。
- **REP002 锂电池鼓胀/发热/破损**：按EPA/FAA 2026信息重写：鼓胀即损坏；热失控征兆时优先撤离而非搬运；损坏电池不得普通垃圾/回收。
- **REP005 无焊接条件的接线**：把“摸查接头温升”改为更安全的低负载观察/测温/手背靠近，避免故障接头灼伤。
- **REP008 螺丝松动与滑牙**：增加塑料柱临时贯穿修复时对背面PCB/电池/线束和金属屑的检查。
- **REP017 太阳能充电不工作的排查**：补充万用表直流电压档和禁止电流档并联，降低现场测量短路风险。
- **CMP003 无伤害外围声响报警**：彻底去除绊线式触发，改为可见、触碰式声响提醒，降低对人和野生动物的伤害风险。
- **CMP007 强风前营地加固**：去除“入口/低侧必须朝主风向”的过度概括，改为按庇护所设计最小化迎风面。
- **TOL001 平结：同粗绳捆扎**：把平结用途收窄到捆束，避免误用于两绳连接或关键承重。
- **TOL004 卡车结：拉紧营绳**：把原先未定义的“不会滑动小环”改为普通用户可执行的绳耳单结环，并明确仅限低风险营绳。
- **TOL006 简易地面锚点**：去掉单一“向远离帐篷方向倾斜”的万能角度说法，改为按土质/地钉设计和实际受力测试。
- **TOL010 防水布集雨**：明确首段雨水冲洗量取决于污染程度而非固定时间，且收集后仍需按水源风险处理。
- **FOD002 断电后的易腐食物判断**：按CDC当前断电食品安全指引明确“冷藏4小时”与“冷冻仍有冰晶或≤4°C”的判断。
- **FOD003 罐头与包装食品检查**：补充“没有异味也不能证明安全”，避免把气味当作排除肉毒等风险的方法。
- **FOD004 生熟分开与手卫生**：明确肥皂水优先及免洗手液在明显脏/油手上的局限。

## 机器校验

- 100 个 Card ID 唯一。
- 6 个分类范围连续且计数一致。
- 32 个快速入口均指向有效卡片。
- 每卡固定 6 节且正文非空。
- 所有内部卡片引用有效。
- 所有 source key 均存在于 sources.json。
- manifest / categories / cards.idx / cards.dat / quick.idx CRC32 全部重算并通过。
- Host 端按 FT02_FieldManual.cpp 相同布局反向解析，100/100 与 cards_source.json 逐字段一致。
- 单卡最大二进制正文长度：1555 bytes，小于运行时 4096 bytes 缓冲限制。
