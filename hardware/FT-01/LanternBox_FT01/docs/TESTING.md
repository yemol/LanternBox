# 测试与验收

## 状态说明

### 已有实机反馈确认

- FT01 原生 Meshtastic 频道消息可被手机接收。
- FT01 在手机节点列表中显示绿色加密标记。
- 手机单发 PKI 私信可被 FT01 接收和解密。
- 非阻塞接收修复后，通信页按键响应恢复正常。
- 路由 ACK、消息去重等 v0.5.1f 之前的主要链路已完成阶段性实机验证。

### v0.5.2e 集成后仍需回归

- 网络终端列表与滚动选择。
- FT01 向指定终端发送 PKI 私信。
- 50 条消息容量与首尾循环。
- GNSS 坐标附加。
- 离开通信页后的后台广播与私信接收。
- 录音期间后台收包的稳定性。

## 1. 构建门禁

- [ ] Flash Size 为 8MB。
- [ ] Partition Scheme 为 `8M with spiffs (3MB APP/1.5MB SPIFFS)`。
- [ ] Arduino 编译成功。
- [ ] 完整链接成功。
- [ ] 记录 `Sketch uses`、`Maximum` 与 RAM 输出。
- [ ] `Maximum` 不是 1,310,720 字节。
- [ ] `Ft01Secrets.h` 未被 Git 跟踪。

## 2. 基础启动

- [ ] 首页、键盘、SD、GNSS、任务、录音和日志页面可进入。
- [ ] LoRa 后台初始化成功。
- [ ] 手机节点列表中 FT01 为绿色锁。
- [ ] 按 `B` 后可学习其他节点的名称和公钥。

## 3. 频道广播

1. FT01 发送唯一消息，手机只收到一条。
2. 手机广播唯一消息，FT01 只入箱一条。
3. 存在中继副本时诊断页 `Dup` 增加，但消息数不增加。
4. 来源显示优先为 `short_name`。

- [ ] FT01 → 手机广播成功。
- [ ] 手机 → FT01 广播成功。
- [ ] 去重成功。

## 4. PKI 私信与 ACK

1. 手机从 FT01 节点详情页发送私信。
2. FT01 显示 `PKI 私信` 和正确正文。
3. 手机端由“送达不确定”更新为已送达。
4. 诊断页 `Ack` 增加，`Decrypt Fail` 保持为 0。
5. 在网络终端页选择一个 `PKI` 节点，FT01 向其发送私信。

- [ ] 手机 → FT01 私信成功。
- [ ] ACK 成功。
- [ ] FT01 → 指定终端私信成功。

## 5. 节点目录

- [ ] `M/O` 可进入目录。
- [ ] 节点超过 5 个时可平滑滚屏。
- [ ] 方向键、`N/P` 可选择。
- [ ] 名称显示 `short_name → long_name → 编号`。
- [ ] 无公钥节点显示 `---`，按 Enter 后请求 NodeInfo而不是发送明文。
- [ ] 重启后已缓存节点名称与公钥仍可用。

## 6. 50 条消息与环形浏览

- [ ] 连续写入 50 条后数量正确。
- [ ] 第 51 条覆盖最旧记录。
- [ ] 最新消息按 `N` 跳到最旧消息。
- [ ] 最旧消息按 `P` 跳回最新消息。
- [ ] 只有 1 条时 `N/P` 不越界。
- [ ] 新消息到达后自动回到最新消息。

## 7. GNSS 附加

### 有效定位

- [ ] 编辑页显示 `GPS:ON`。
- [ ] 广播正文只生成一条消息，并包含 `[GPS:lat,lon]`。
- [ ] PKI 私信同样附带坐标。

### 无效或过期定位

- [ ] 编辑页显示 `GPS:--`。
- [ ] 纯文字仍正常发送。
- [ ] 不附带旧坐标，不阻塞发送。

## 8. 后台接收

分别让 FT01 停留在首页、地图、任务、日志、同步和帮助页面，从手机发送消息：

- [ ] 每个页面都可收到频道广播。
- [ ] 每个页面都可收到 PKI 私信并回 ACK。
- [ ] 首页出现 `M1` 至 `M9+`。
- [ ] 进入通信页后消息可见，未读计数清零。
- [ ] 页面按键不因后台收包出现数秒卡顿。

## 9. 录音压力测试

1. 开始录音。
2. 同时从手机发送广播和私信。
3. 停止并保存 WAV。
4. 回放录音。

- [ ] 两条消息均收到。
- [ ] 私信 ACK 正常。
- [ ] WAV 可保存和回放。
- [ ] 没有明显音频断裂、SPI 错误或设备重启。
