# 监督练习证据记录

## 用途
用于 ASSIST 或 SUPERVISED 阶段留下实际表现证据。仅听讲、观看视频或口头自述不能替代一次有范围、有监督的实际练习。

## 操作步骤
1. 写 skill_name、learner、trainer、任务、设备/材料和使用的 CURRENT Guide 版本。
2. 练习前让学习者复述目标、关键步骤、禁止项和停止线。
3. 训练者记录学习者实际完成的步骤、提示次数、误操作和主动停止表现。
4. 记录检查、收尾、工具归位和异常交接是否完成。
5. 训练后由学习者复述哪里不确定，训练者给出具体下一练习项。
6. reviewer 判断保持等级、升级、降级或复训；系统不自动作出授权。

## 判断标准
- 记录包含真实任务 evidence 而非只写“已培训”。
- 停止线和纠错表现被单独记录。
- 一次成功不会自动变成 INDEPENDENT。

## 风险提示
停止条件：练习出现危险信号、学习者越过停止线、监督者无法持续在场或任务超出训练范围时，立即停止练习。

不得使用自动评分、成员排名或系统推断授权；INDEPENDENT 必须有实际执行 evidence 和人工确认。

## 离线替代方案
改用无能量、无锋刃、空载或纸面演练；高风险任务只观察和复述，不进行模拟危险动作。

## 记录与交接
保存 practice_id、task_id、Guide version、步骤结果、提示/错误、stop response、trainer、reviewer 和决定。

## 相邻领域边界
业务域决定练习是否安全、哪些动作可模拟；Records 只保存证据，不自动晋级。
