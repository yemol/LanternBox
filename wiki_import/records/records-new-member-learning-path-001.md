# 新成员低风险学习路径

## 用途
用于新成员加入或成员转入陌生任务域时建立最小学习顺序。目标是安全融入和知识可传承，不是建立 HR 入职或考核系统。

## 操作步骤
1. 说明人员责任人、紧急停止方式、禁区、敏感记录边界和 CURRENT 资料位置。
2. 确认成员能找到每日摘要、对应业务域 Guide、任务板和交接位置。
3. 选择低风险首任务，明确 allowed、prohibited 和 supervised 部分。
4. 先 OBSERVE，再 ASSIST；每阶段让成员复述停止线并完成纸面或实物交接。
5. 安排 SUPERVISED 实际练习，记录 evidence、纠错和 next_review。
6. 只有业务域人工确认后才授予限定范围的 INDEPENDENT。

## 判断标准
- 新成员知道遇到不确定时找谁和如何停止。
- 首任务不会暴露高风险、敏感资料或唯一关键资源。
- 学习路径与技能记录和 CURRENT 版本相连。

## 风险提示
停止条件：成员未理解停止线、无监督者、当前现场有危险、任务超出低风险范围或敏感信息无需共享时，停止推进学习。

不得使用自动评分、成员排名或系统推断授权；INDEPENDENT 必须有实际执行 evidence 和人工确认。

## 离线替代方案
只进行场地介绍、纸本索引查找和 OBSERVE，不因任务积压安排高风险操作。

## 记录与交接
保存 learner、orientation date、资料版本、首任务、等级、trainer、evidence、限制和下一学习步骤。

## 相邻领域边界
Organization 决定新成员安排和制度；各业务域决定任务标准；Records 管学习证据和版本位置。
