# 首件确认

## 用途
小批量制作先完成首件检查，再继续后续重复件。并保留可核对的现场状态、停止条件和下一步。适用于完全离线、资源有限的小团队。本条只处理资源有限条件下的小批量重复制作，不替代具体加工技术、危险处置或长期储藏规则。

## 操作步骤
1. 把“首件确认”对应到具体任务、对象、负责人和现场位置。
2. 用正式材料完成并确认首件
3. 冻结模板、关键尺寸和步骤版本后再重复
4. 逐件检查，连续同类缺陷出现时冻结整批
5. 状态变化时同步标签、任务板或交接卡，口头说明不能替代记录。
6. 收尾时由另一名成员对照实物复核，无法复核的对象进入待检或暂停区。

## 现场细则
首件使用正式材料和正式工序，不以练习料代替；尺寸、连接、边缘、功能和标签全部通过后才能作为后续件比较基准。

## 判断标准
- 首件、模板、步骤版本、逐件检查和批次状态相互对应。
- 任务号、批次号或物品号能够对应现场实物；任何暂停项都有位置、原因、下一步和负责人。
- 放行、返工、隔离、报废或转交均留下检查痕迹，不依赖 ERP、网络或云端库存系统。

## 风险提示
停止条件：首件未确认、模板尺寸有争议、同类缺陷连续出现、材料批次混乱或操作者疲劳时停止整批。

材料来源不明、半成品状态不明、成品未经检查、承重件裂纹、锐边或松动不可控、污染材料以及疲劳操作，均不能靠赶进度绕过。先隔离并转对应相邻领域判断。

## 替代方案
- 没有印刷表格时，用纸片、木牌或胶带编号，在一本总账中保留同号记录。
- 空间不足时，用地面线、编号箱或固定角落建立临时区，仍需分开待检、合格和隔离状态。
- 人手不足时缩小批量，优先完成清点、标记和低风险检查，高风险步骤延后。

## 记录与交接
- 最少记录日期、任务或批次、对象状态、位置、负责人、检查结果和下一步。
- 状态改变时划掉旧状态并签名，不擦除失败、返工或 near miss 记录。
- 交接时由接手人根据实物复述，不能只接收一张脱离现场的纸。

## 相邻边界
- Manufacturing 定义每件怎么制作，Organization 管人员制度；本条只保持批次过程可重复和可检查。
- Production System / Workshop 只负责让流程可重复、可检查、可交接、可复盘。
- 涉及武器、危险化学品、高压电气、自动化生产线或专业质量认证时，本条不适用。
