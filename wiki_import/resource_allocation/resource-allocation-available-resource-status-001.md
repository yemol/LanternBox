# 可分配资源状态卡

## 用途

把“仓里有多少”改写成“现在有多少可以安全分配”。总库存只是起点；污染、破损、隔离、来源不明、状态未核对和已经承诺给其他用途的数量，都不能重复进入可分配量。

## 适用场景

适用于食物、饮水、能源、燃料、医疗与卫生耗材、工具、零件、原材料和生产耗材的快速盘点。保存质量由 Storage 或对应专业域判断，本卡只接收状态结论。

## 准备材料

实物清单、库存卡、隔离标签、最近领用记录、补给记录、纸笔和统一计量单位。

## 操作步骤

1. 按物品、单位、位置和批次列出账面总量，不把不同单位直接相加。
2. 对照实物，将数量拆成 `USABLE`、`UNAVAILABLE`、`RESERVED`、`UNCERTAIN` 四栏。
3. `UNAVAILABLE` 写明污染、破损、隔离、过期或专业域禁用原因；不得移回可用栏。
4. `RESERVED` 写明用途、reserve 等级、释放 trigger 和复查时间，避免被再次分配。
5. `UNCERTAIN` 写明缺失证据和下一确认动作；确认前按不可分配处理。
6. 预计补给另列来源、最早日期和置信度，不并入当前 `USABLE`。
7. 由第二人抽查高风险和低库存条目，签记本次可分配量与有效时间。

## 判断标准

- 每种资源只有一个单位口径，实物位置可找到。
- 可分配量不含不可用、已预留和待确认数量。
- 补给预测与当前库存分栏记录。
- 状态卡写有检查时间、证据来源和下一次复查。

## 风险提示

账面数字不能覆盖实物状态。资源稀缺也不能降低污染、漏液、鼓包、冒烟、来源不明或隔离物的禁用标准。

## 停止条件

出现设备冒烟、火花、异常热、电池鼓包或漏液、化学异味、污染食水、人员伤害时，停止资源盘点中的操作并转 Safety / Fire / Medical。状态无法确认的关键资源不得分配。

## 替代方案

无法精确称量时，使用完整包装数、固定容器或满/半/低三级估算，并标为低置信度。无法完成全量盘点时，先查饮水、关键能源、必要医疗耗材和唯一零件。

## 记录建议

记录资源、单位、总量、四种状态量、证据、负责人、补给置信度、有效时间和下一复查。

## 领域边界

Storage 判断保存和隔离，Energy/Water/Food/Medical 等专业域判断安全可用性，Records 保存原始事实；Resource Allocation 只使用这些结论计算可分配量。
